Library EqCat.Axioms

Axioms of EqCat∞

The provable-equality relation t == t' on raw terms. Reference: "Equational Reasoning in ∞-Categories", Figure 2.
Conventions:
  • dim e = Some n is written explicitly; partial dimensions are not implicit.
  • For each premise of the form "dim x >= k" in the paper, we require dim e = Some d with d ≥ k.
  • Equality of the theory is the inductive relation eq_cat, NOT Coq's built-in =.


Require Import Arith Lia.
Require Import Syntax.

Module AxiomsF (G : GEN).
Include SyntaxF G.

Reserved Notation "a == b" (at level 70, no associativity).

Inductive wf : Term → nat → Prop :=
| wf_gen :
    ∀ g, wf (gen g) (gen_dim g)
| wf_src :
    ∀ e n, wf e (S n) → wf (src e) n
| wf_tgt :
    ∀ e n, wf e (S n) → wf (tgt e) n
| wf_id :
    ∀ e n, wf e n → wf (id e) (S n)
| wf_comp :
    ∀ k a b n,
      wf a n → wf b n →
      k < n →
      iter_src (n - k) a == iter_tgt (n - k) b →
      wf (comp k a b) n

with eq_cat : Term → Term → Prop :=

Structural equality axioms (E1–E8)

E1: reflexivity.
| E1_refl :
    ∀ x, x == x

E2: symmetry.
| E2_sym :
    ∀ x y, x == y → y == x

E3: transitivity.
| E3_trans :
    ∀ x y z, x == y → y == z → x == z

E4 ("equality preserves dimension") is not a constructor — its conclusion is an equality of option nat, not of Term. It is derivable; see eq_cat_dim below.
E5: src is a congruence, where defined.

| E5_src :
    ∀ x y n,
      x == y → wf x (S n) → wf y (S n) →
      src x == src y

E6: tgt is a congruence, where defined.

| E6_tgt :
    ∀ x y n,
      x == y → wf x (S n) → wf y (S n) →
      tgt x == tgt y

E7: composition is a congruence.

| E7_comp :
    ∀ x y z w n d,
      x == y → z == w →
      wf (comp n x z) d → wf (comp n y w) d →
      comp n x z == comp n y w

E8: id is a congruence.
| E8_id :
    ∀ x y, x == y → id x == id y

∞-categorical axioms (IC1–IC13)

IC1: dim x >= 2 ==> src (src x) == src (tgt x).

| IC1 :
    ∀ x n,
      wf x n → n ≥ 2 →
      src (src x) == src (tgt x)

IC2: dim x >= 2 ==> tgt (src x) == tgt (tgt x).

| IC2 :
    ∀ x n,
      wf x n → n ≥ 2 →
      tgt (src x) == tgt (tgt x)

IC3: src (id x) == x.

| IC3 :
    ∀ x n, wf x n → src (id x) == x

IC4: tgt (id x) == x.

| IC4 :
    ∀ x n, wf x n → tgt (id x) == x

IC5: dim x = dim y = n+1 ==> src (y on x) == src x.

| IC5 :
    ∀ x y n,
      wf (comp n y x) (S n) →
      src (comp n y x) == src x

IC6: dim x = dim y = n+1 ==> tgt (y on x) == tgt y.

| IC6 :
    ∀ x y n,
      wf (comp n y x) (S n) →
      tgt (comp n y x) == tgt y

IC7: dim x = dim y > n+1 ==> src (y on x) == src y on src x.

| IC7 :
    ∀ x y n d,
      wf (comp n y x) d → d > S n →
      src (comp n y x) == comp n (src y) (src x)

IC8: dim x = dim y > n+1 ==> tgt (y on x) == tgt y on tgt x.

| IC8 :
    ∀ x y n d,
      wf (comp n y x) d → d > S n →
      tgt (comp n y x) == comp n (tgt y) (tgt x)

IC9: associativity. dim x = dim y = dim z > n ==> (x on y) on z == x on (y on z).

| IC9 :
    ∀ x y z n d,
      wf (comp n (comp n x y) z) d →
      wf (comp n x (comp n y z)) d →
      comp n (comp n x y) z == comp n x (comp n y z)

IC10: exchange. dim x = dim y = dim z = dim w > max(m,n), m <> n ==> (x on y) om (z on w) == (x om z) on (y om w).

| IC10 :
    ∀ x y z w m n d,
      wf (comp m (comp n x y) (comp n z w)) d →
      wf (comp n (comp m x z) (comp m y w)) d →
      m ≠ n →
      comp m (comp n x y) (comp n z w) ==
      comp n (comp m x z) (comp m y w)

IC11: left identity. d = dim x > n ==> x on (id^{d-n} (src^{d-n} x)) == x.

| IC11 :
    ∀ x n d,
      wf x d → d > n →
      wf (comp n x (iter_id (d - n) (iter_src (d - n) x))) d →
      comp n x (iter_id (d - n) (iter_src (d - n) x)) == x

IC12: right identity. d = dim x > n ==> (id^{d-n} (tgt^{d-n} x)) on x == x.

| IC12 :
    ∀ x n d,
      wf x d → d > n →
      wf (comp n (iter_id (d - n) (iter_tgt (d - n) x)) x) d →
      comp n (iter_id (d - n) (iter_tgt (d - n) x)) x == x

IC13: dim x = dim y > n, src^{d-n} y = tgt^{d-n} x ==> id (y on x) == id y on id x.

| IC13 :
    ∀ x y n d,
      wf (comp n y x) d → d > n →
      id (comp n y x) == comp n (id y) (id x)

where "a == b" := (eq_cat a b).

End AxiomsF.
